# DOCK TB Uganda — design direction

## Theme Name
Clinical Signal / Pastel Operations

## Intro
A calm, high-trust surveillance console that makes registration momentum and data quality legible in seconds.

## Design movement
Minimal clinical operations UI: soft surfaces, precise geometry, low-contrast borders, and a restrained lavender-to-blue accent system.

## Core principles
- Prioritize the registration cascade and KPI scan path above supporting context.
- Use generous spacing and rounded containers to make a dense operational dashboard feel calm.
- Keep labels plain and human: “Diagnosed positive”, “Started treatment”, “Unresolved flags”.
- Pair every chart with a short interpretation so the visual is actionable, not decorative.

## Color philosophy
White and warm off-white canvas, ink navy for hierarchy, lavender for active navigation and cohort highlights, mint for healthy sync states, peach for caution, and blue-violet for diagnostic measures.

## Layout paradigm
A fixed left rail anchors navigation. The main workspace uses a slim context header, horizontal filters, four KPI cards, then a registration cascade followed by a two-column chart row and a data table. On small screens the rail becomes a compact top row and grids collapse to one column.

## Signature elements
- A small rounded square mark with a split-register / cross motif.
- Thin lavender connectors between cascade stages.
- Tiny uppercase section labels and quiet helper copy under headings.
- Status pills with a dot indicator instead of loud badges.

## Interaction philosophy
Low-friction and reversible. Filters update the viewing context immediately, tabs swap the active operational lens, and export is available without hiding the dashboard state.

## Animation
Use only short opacity/translate transitions for tab state, nav focus, and filter feedback. No looping motion or decorative animation.

## Typography system
System UI / Inter-like sans serif. Strong 30px page title, 22–24px card values, 12px uppercase eyebrow labels, and compact 13–14px table text.

## Brand essence
Evidence that moves care forward.

## Brand voice
Quietly confident, operational, specific, supportive.

## Wordmark / logo
“DOCK TB” wordmark paired with a compact abstract mark: a lavender rounded field with a navy cross and two register lines.

## Signature brand color
Lavender #8C7CF6, used sparingly for active navigation, connectors, and primary highlights.

## Asset decision
This is a functional data/control dashboard, so no additional imagery is needed beyond the required project-specific logo and favicon identity.
